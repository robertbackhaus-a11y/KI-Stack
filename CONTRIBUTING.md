# Contributing

Changes must be delivered as complete, consolidated files. Patch fragments and manual copy-and-paste insertion instructions are not accepted for release packages.

Every defect correction requires:

1. root-cause analysis;
2. a permanent regression test;
3. a new complete package version;
4. updated release notes and regression registry;
5. successful repository validation;
6. target-system SelfTest, DryRun and Execute before stable promotion.

Do not modify a frozen reference module unless a mandatory dependency is documented.
