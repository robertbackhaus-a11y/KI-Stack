# Optionaler Modellcache

Complete Installer 2.3.2 lädt fehlende Modelle einschließlich des ausschließlich für Embeddings verwendeten Nomic Q4_K_M automatisch aus revisionsgebundenen Manifestquellen. Dieses Verzeichnis ist ausschließlich ein optionaler Cache/Preload und keine Installationsvoraussetzung.

Vorhandene Ziele und Cachekandidaten werden nur nach exakter Prüfung von Dateiname, Größe und SHA-256 akzeptiert. Gültige Ziele werden ohne erneuten Download wiederverwendet; unterbrochene Downloads unterstützen, sofern verfügbar, Resume.

Heretic ist ausschließlich Chat-LLM, Nomic ausschließlich Embedding-Modell und das offizielle Qwen-Artefakt wird nur durch Z-Image verwendet.
