# KI-Stack Complete Installer 2.2.0

Complete Installer 2.2.0 preserves the validated 2.1.3 operations contract and the existing OpenWebUI/ComfyUI integration while updating Models / Workflows to 1.4.0.

The installer embeds no model files and has no Git acquisition path. It reuses existing models only after matching file size and SHA256 and acquires only missing models from the pinned external HTTPS contracts. The eight added KREA, Pony SDXL and WAN 2.2 model dependencies total 47,356,936,991 bytes.

The package is explicitly not a fully offline installer. Existing-installation behavior inherits the target-validated Complete Installer 2.1.3 operations state and the target-system validation of the five canonical workflows. No new bare-metal fresh-install claim is made.
