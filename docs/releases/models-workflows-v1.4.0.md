# KI-Stack Models / Workflows 1.4.0

Status: `TargetSystemValidated`.

The release contains five canonical workflows: the unchanged accepted FLUX2 UI and API workflows plus `KREA-Realism-Official-Template.json`, `PONY-SDXL-Control-QuickTest-v2.json` and `WAN2.2-5B-Official.json`.

The three added workflows each passed one load test and one functional target-system run. Only the unconnected `MarkdownNote` annotations in KREA and WAN were replaced by the available standard `Note` node.

Eight external model contracts total 47,356,936,991 bytes. Model files are not included in Git or release ZIPs. Existing files are reused only when size and SHA256 match; only missing files are acquired from pinned HTTPS sources. License and redistribution restrictions remain with their respective upstream models.

Superseded duplicates, broken backups, archives and `OpenWebUI-Generation-Mapping.json` remain excluded from the canonical workflow set.
