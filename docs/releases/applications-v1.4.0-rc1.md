# KI-Stack Applications v1.4.0-rc1

Adds LM Studio and Open WebUI as the sixth Execute module.

## Included

- LM Studio via exact winget package ID with post-install state validation.
- Open WebUI 0.10.2 in a dedicated Python virtual environment.
- Local-only defaults for ports 1234 and 8080.
- Managed start/stop scripts, persistent data directory and rollback journal.

Target-system validation is pending.
