# KI-Stack Complete Installer 2.2.1

Complete Installer 2.2.1 embeds Models / Workflows 1.4.1 while preserving the validated OpenWebUI, ComfyUI and operational contracts of 2.2.0.

The installer is not offline and contains no models. Existing files are reused only after size and SHA256 verification. Seven Hugging Face model contracts require manual external placement; Pony V6 XL may be acquired automatically from fixed Civitai model version `290640`.
