# Rollback contract

The execute path records whether the managed profile and tool existed and stores only their OpenWebUI forms. Rollback restores or removes exactly `ki-stack-18bravo` and `ki_stack_ballistics_calculator`. The protected profiles `ki-stack-allgemein` and `ki-stack-it-technik`, their bindings, user data and foreign objects are never rollback targets. API keys are never serialized.
