# Optional model cache for Complete Installer 2.3.1

This directory is optional. Visual Models / Workflows 2.0.2 reuses correctly named files only after exact size and SHA-256 verification. Missing artifacts are downloaded from the revision-bound manifest sources with resumable transaction state and verified before atomic activation.

No model weight is embedded in the Complete Installer. An empty directory is a supported Greenfield installation state.

Preloads are never required. Heretic is chat-only, Nomic embedding-only, and the official Qwen artifact is used only by Z-Image.
