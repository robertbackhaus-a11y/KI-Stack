# Optionaler Modellcache für Complete Installer 2.4.0-rc11

Dieses Verzeichnis ist optional. Visual Models / Workflows 2.0.3 verwendet passend benannte Dateien nur nach exakter Größen- und SHA-256-Prüfung. Fehlende Artefakte einschließlich Nomic Q4_K_M werden aus den revisionsgebundenen Manifestquellen mit fortsetzbarem Transaktionszustand geladen und vor der atomaren Aktivierung geprüft.

Der Complete Installer enthält keine Modellgewichte. Ein leeres Verzeichnis ist ein unterstützter Greenfield-Installationszustand.

Preloads sind niemals erforderlich. Heretic ist ausschließlich Chat-LLM, Nomic ausschließlich Embedding-Modell und das offizielle Qwen-Artefakt wird nur durch Z-Image verwendet.
