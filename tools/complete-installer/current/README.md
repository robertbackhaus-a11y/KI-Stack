# KI-Stack Complete Installer 2.3.0-rc16

Repository-validated release candidate based on Complete Installer 2.2.9.

- Heretic is the only LM Studio chat LLM.
- Nomic is embedding-only.
- ComfyUI is limited to Z-Image Turbo and WAN2.2 T2V 14B with both LightX2V four-step LoRAs.
- OpenWebUI uses Visual Pack 2.0.5-rc2. MP4 output is a single persistent download attachment.
- No model weights, secrets, personal paths, or Git runtime dependency are included.

Run `Start-KIStack-Complete-Installer-SelfTest.cmd` before installation. Building and testing this package does not access or mutate the target system.
